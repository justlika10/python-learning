# Life Expectancy Analysis
## Goal
Compare life expectancy in China, Georgia, and the Netherlands using data from a CSV file.

## Analysis
I used Python to calculate the change in life expectancy between the first and last available years for each country. I also compared the latest available life expectancy values.

## Finding
The Netherlands had the largest change in life expectancy among the three countries over the period analysed.
